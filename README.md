Лабораторна робота №5

Моделювання часових рядів за допомогою рекурентних нейронних мереж

Мета роботи

Дослідити принцип роботи рекурентних нейронних мереж Елмана та навчити мережу працювати з послідовностями бінарних даних.

Завдання 1

Розпізнавання двох одиниць поспіль

Було створено рекурентну нейронну мережу Елмана для аналізу бінарної послідовності та визначення появи двох одиниць підряд.

Основні етапи:

- створення вхідної послідовності;
- формування цільової послідовності;
- створення мережі Елмана;
- навчання мережі;
- тестування на нових даних;
- дослідження впливу кількості нейронів прихованого шару.

Результати:

Мережа успішно навчилась визначати появу двох одиниць поспіль у вхідній послідовності та правильно працювала на тестових даних.

Завдання 2

#Виконання XOR у динаміці

Було реалізовано рекурентну нейронну мережу Елмана для виконання логічної операції XOR між поточним та попереднім елементами послідовності.

Основні етапи:

- формування послідовності бінарних даних;
- реалізація таблиці істинності XOR;
- навчання рекурентної мережі;
- перевірка роботи на тестових даних;
- аналіз результатів навчання.

Результати:

Мережа успішно виконувала логічне перетворення XOR та правильно аналізувала часові залежності між елементами послідовності.

Використані технології

- MATLAB
- Neural Network Toolbox
- Рекурентні нейронні мережі Елмана
- Алгоритм навчання Levenberg-Marquardt (`trainlm`)

Висновок

У ході лабораторної роботи було досліджено можливості рекурентних нейронних мереж для обробки часових рядів та послідовних даних. Отримані результати підтвердили ефективність мережі Елмана для задач розпізнавання послідовностей та аналізу часових залежностей.
